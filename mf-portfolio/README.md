# India Mutual Fund Portfolio Analyzer

Compares what a set of Indian mutual funds held in two months: imports the converted monthly portfolio files from a local folder (or loads the built-in sample), maps company names by ISIN with a human check, and builds the summary, holdings by fund and charts.

Tool page: https://www.tigzig.com/mf-portfolio-processor

## Files

- `XLWINGS_PORTFOLIO_ANALYZER.xlsx`: the tool. The Python code is inside the workbook.
- `main_mf_portfolio.py`: the same code as a plain file, to read or to give to an AI coder.
- `requirements.txt`: the packages xlwings Lite installs for this workbook.

## How to run

Open the workbook in Excel and start xlwings Lite (Home > Add-ins). Click the numbered buttons in order. The HOW_IT_WORKS sheet explains each step.
