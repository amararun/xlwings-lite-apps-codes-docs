# Technical Analysis Reports

Prices for any Yahoo Finance symbol from the TIGZIG Yahoo Finance API, daily and weekly indicators (EMA, RSI, ROC, MACD, Bollinger Bands, Stochastic, Williams %R) computed in pandas, and charts. A second button asks the TIGZIG Technical Analysis API for an AI-written report and returns PDF and HTML links.

Tool page: https://www.tigzig.com/technical-analysis-report

## Files

- `TECHNICAL_ANALYSIS_PDF_HTML_V2_1225.xlsx`: the tool. The Python code is inside the workbook.
- `main_technical_analysis.py`: the same code as a plain file, to read or to give to an AI coder.
- `requirements.txt`: the packages xlwings Lite installs for this workbook.

## How to run

Open the workbook in Excel and start xlwings Lite (Home > Add-ins). Click the numbered buttons in order. The HOW_IT_WORKS sheet explains each step.
