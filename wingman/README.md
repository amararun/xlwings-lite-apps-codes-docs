# WINGMAN Function Examples

Examples of the =WINGMAN() function built into xlwings Lite: pulling clean phone numbers out of messy text, and a judgment call on each customer from a table of fields. There is no Python code in this workbook; the formulas are on the sheets.

Tool page: https://www.tigzig.com/xlwings-starter

## Files

- `XLWINGS_LITE_WINGMAN.xlsx`: the tool. The Python code is inside the workbook.

## How to run

Open the workbook in Excel and start xlwings Lite (Home > Add-ins). Each example sheet has WINGMAN formulas; they recalculate once a model provider is set up.

## Keys and setup

Set up a model provider in xlwings Lite > Settings > Local > Wingman.
