# YLENS: Yahoo Finance Analyzer

Company profile, annual P&L, balance sheet and cash flow, quarterly P&L, daily and weekly prices with indicators and charts, and an AI-written technical report (PDF and HTML), for any Yahoo Finance symbol.

Tool page: https://www.tigzig.com/yahoo-finance-analyzer

## Files

- `YLENS_YAHOO_FINANCE_ANALYZER_Z_1225.xlsx`: the tool. The Python code is inside the workbook.
- `main_yahoo_finance.py`: the same code as a plain file, to read or to give to an AI coder.
- `requirements.txt`: the packages xlwings Lite installs for this workbook.

## How to run

Open the workbook in Excel and start xlwings Lite (Home > Add-ins). Click the numbered buttons in order. The HOW_IT_WORKS sheet explains each step.
